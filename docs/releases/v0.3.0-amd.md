# VRAM Game Optimizer v0.3.0-amd

First AMD preview for Linux using the kernel AMDGPU driver.

## AMD package

- Selects AMDGPU/sysfs monitoring by default, including on mixed NVIDIA/AMD systems.
- Reads driver-reported total, used and free VRAM for each AMDGPU device.
- Reports optional GTT usage separately from VRAM.
- Filters by AMD PCI vendor and the active amdgpu driver; ignores display connectors and duplicate device entries.
- Keeps the AMD package selection after per-user installation.
- Includes the common Steam launcher, desktop profiles, CPU/I/O priorities, optional GameMode, RAM options and recovery watchdog.

Requires Linux, Python 3.10+ and a running native Steam client. AMD memory monitoring uses readable AMDGPU counters under `/sys/class/drm/card*/device/`. NVIDIA tools and ROCm are unnecessary.

Extract the package and run `./game-optimizer`. Confirm the package with `./game-optimizer --version` or inspect `./game-optimizer diagnose --json`.

## Validation and limits

This is a preview. Packaging and AMD counter handling were checked with simulated sysfs devices. No physical AMD GPU was available for validation, and no FPS improvement is claimed. Feedback from actual AMD systems is needed.

On APUs the driver-reported VRAM region may be reserved system RAM. GTT is GPU-accessible system memory and is not added to the free-VRAM figure. Per-process AMD GPU memory reporting is not implemented. Missing or unreadable counters do not prevent the common optimization features from running.
