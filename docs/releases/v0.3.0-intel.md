# VRAM Game Optimizer v0.3.0-intel

First Intel preview for Linux using the kernel i915 and Xe DRM memory queries.

## Intel package

- Selects Intel monitoring by default, including on hybrid systems, without invoking NVIDIA or AMD monitoring.
- Queries memory regions through the read-only i915 MEMORY_REGIONS and Xe DEVICE_QUERY interfaces.
- Reports dedicated memory capacity and available usage estimates for discrete Intel GPUs, including Arc.
- Identifies shared-memory integrated GPUs without presenting system RAM as dedicated VRAM.
- Keeps unavailable measurements explicit in terminal diagnostics, the optional GUI and session reports.
- Filters by Intel PCI vendor and the active i915/xe driver; ignores display connectors and duplicate device entries.
- Keeps the Intel selection after per-user installation.
- Includes the common Steam launcher, desktop profiles, CPU/I/O priorities, optional GameMode, RAM options and recovery watchdog.

Install Python 3.10+, extract an archive and run `./game-optimizer`. Native Steam should already be running and signed in. GPU monitoring requires the kernel i915 or xe driver, memory-query support and permission to open the corresponding `/dev/dri` device. No Python dependencies or administrator privileges are required by the application.

The application interface is currently Polish. The main README and these release notes are English. License: BSD-3-Clause.

## Validation and current limits

This is a preview validated with simulated i915/Xe ioctl responses, sysfs fixtures, package extraction and temporary-prefix installation checks. Physical Intel hardware was not available. No measured FPS gain or fixed VRAM saving is claimed.

Some kernels return placeholder usage values without monitoring capabilities. An all-zero usage estimate is therefore conservatively shown as unavailable, even if a GPU might actually be empty. Capacity can still be reported. Missing permissions, older unsupported queries and malformed responses leave monitoring unavailable while common optimization features continue to work. Run the optimizer as your regular user.

Integrated graphics share system RAM and have no separate VRAM pool in these queries. Use the RAM measurements to inspect system memory. Per-process Intel GPU memory reporting is not implemented. Selecting the Intel package does not select the rendering GPU for the game.

Query structures and memory classes follow the [Linux DRM user API](https://docs.kernel.org/gpu/driver-uapi.html#drm-i915-uapi) and its [Xe interface](https://docs.kernel.org/gpu/driver-uapi.html#drm-xe-uapi). Global usage estimates can change while the desktop and other applications are running.
